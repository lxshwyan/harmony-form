# Code of conduct

We want this project to be a practical, respectful place for HarmonyOS developers.

## Expected behavior

- Discuss code, APIs and evidence rather than personal characteristics.
- Give actionable feedback and assume good intent while remaining precise about risks.
- Protect private business data, credentials and vulnerability details.
- Respect different experience levels, languages and accessibility needs.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate disclosure of private information, spam and sustained disruption are not accepted in issues, pull requests or other project spaces.

## Enforcement

Report conduct or security-sensitive concerns privately through the repository's GitHub Security reporting flow. Maintainers may edit or remove content, lock discussions, reject contributions or restrict participation when necessary. Enforcement decisions should be proportionate, documented privately and focused on keeping the project safe and productive.

This policy applies to all project-managed spaces and to public interactions made on behalf of the project.
